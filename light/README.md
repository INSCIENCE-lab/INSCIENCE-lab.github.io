# 03 Світло — INSCIENCE LAB

Погоджена українська версія лабораторії світла.

- Лабораторія: https://inscience-lab.github.io/light/
- Усі лабораторії: https://inscience-lab.github.io/

Десять інтерактивних дослідів: електромагнітна хвиля, інтерференція та окремі фотонні реєстрації, дифракція, поляризація, заломлення й дисперсія, фотоефект, атомні переходи, молекулярні переходи, атмосферне розсіювання, теплове випромінювання та кольори зір.

Статичний застосунок на HTML/CSS/JavaScript без серверної бази даних. Фізичний час в анімаціях умовний. Журнал зберігається локально в браузері та експортується в CSV. Атмосферний розрахунок виконується в окремому Web Worker.

## Перевірка

Потрібен сучасний Node.js. Залежностей для чисельних тестів немає:

```sh
cd light
npm test
```

Основні моделі — `physics.js`, `atmosphere.js`, `transfer.js`; пояснення — `content.js`, `enhancements.js`; інтерфейс — `app.js`; зображення й графіки — `visuals.js`, `sky-camera.js`.

Для перегляду запускайте HTTP-сервер, а не відкривайте HTML через file://: браузерні ES-модулі й Worker потребують HTTP(S).

## Межі та джерела

Межі кожної моделі, формули та посилання наведено в самому досліді. Атмосфера: сферичний скалярний перенос із багаторазовим розсіюванням; без хмар, атмосферного заломлення й поляризації. Газове поглинання враховано лише для озону. Скінченні спектральна й кутова сітки та статистична вибірка обмежують точність. Кольори конкретного марсіанського заходу не калібровані за фото. Молекулярні енергетичні схеми навчальні, а не спектр довільної реальної молекули.
